Adaptive Intelligence Architecture

Three Flexible AI Modes. Zero Lock-In.

Switch anytime in Customize → Local AI / STT / TTS Settings or config.yaml.

MODE 01

Gemini Key Only

Uses Google's Gemini Live as the primary real-time multimodal engine with native audio turn-taking, screen vision, and camera understanding.

Requires: Gemini Key Cloud Live
Recommended Hybrid
MODE 02

Gemini + Local Fallback

Keeps Gemini Live as primary, automatically hot-swapping to local Ollama or LM Studio if connection drops. Can also speak Gemini responses using local bm_george TTS.

Uninterruptible Auto-Reconnect
MODE 03

Local AI Only

100% offline pipeline. Runs inference via Ollama (127.0.0.1:11434) or LM Studio (127.0.0.1:1234/v1) with Vosk STT and Kokoro ONNX voice synthesis.

No API Key Needed 100% On-Device

4-Category Persistent Memory

Settings → MEMORY

Stored locally on your PC with automatic legacy migration and backups. Voice-created memories are badged VOICE.

Deployment & Setup Manual

Install A.U.R.A v2 in Minutes

Run the 4-step terminal setup below, or grab the latest packaged release archives from the .

01 Clone the Repository 
git clone https://github.com/gitsdp-dev/A.U.R.A_v2-CodeCrafters.git
cd A.U.R.A_v2-CodeCrafters
02 Install Dependencies & Voice Models 
pip install -r requirements.txt
# Automated setup for Vosk & Kokoro ONNX (bm_george):
python setup.py
# Or download models manually:
python scripts\download_models.py
03 Optional: HUD Browser & Screen Agent 
# Built-in QtWebEngine HUD browser + Edge WebView2 (H.264):
pip install PyQt6-WebEngine pythonnet pywebview

# Optional OS Accessibility Tree Screen Agent CLI:
npm install -g agent-desktop
04 Launch A.U.R.A v2 
python main.py

# Run focused voice and agent unit checks:
python -m unittest tests.test_voice_agent
