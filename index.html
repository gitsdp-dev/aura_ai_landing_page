01 — Overview

What is A.U.R.A?

A.U.R.A (Autonomous User-Responsive Assistant) is an intelligent desktop assistant designed to make your computer feel truly alive.

Rather than acting as just another chatbot, A.U.R.A becomes your personal AI operating companion — one that understands natural conversations, automates your computer, researches information, remembers important context, monitors your hardware, interacts with your browser, summarizes files, and even greets you every morning with a personalized briefing.

Built on a modern architecture powered by Google Gemini, A.U.R.A continuously learns your preferences and helps you stay productive without interrupting your workflow — whether you're a student, developer, researcher, content creator, or professional.

ENGINE Google Gemini · Gemini Live API
RUNTIME Python 3.11+
PLATFORM Windows · macOS · Linux
INPUT Voice-first · Hybrid keyboard
MEMORY Persistent, cross-session
STATUS Open Source · v1.0.0

06 — Installation

Up and running in four commands.

During first launch, A.U.R.A guides you through setup, including configuring your free Google Gemini API key.

terminal — aura-setup
// clone the repository
git clone https://github.com/gitsdp-dev/A.U.R.A-CodeCrafters.git
// navigate into the project
cd A.U.R.A-CodeCrafters
// install dependencies
pip install -r requirements.txt
playwright install
// launch A.U.R.A
python main.py
